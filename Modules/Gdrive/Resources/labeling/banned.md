# Banned wording

Never output any of these as (or inside) a description. Add more over time —
one per line, matched case-insensitively as a whole-word substring.

- Photo
- Picture
- Image
- IMG
- Untitled
- Miscellaneous
- N/A

Note: bare "Before" / "After" must not be used on their own (the system prompt
covers this), but they are allowed inside a longer phrase such as
"Yard Clean After Tree Removal", so they are not listed here.
