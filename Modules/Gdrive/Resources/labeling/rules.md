# Business rules

Additional rules for choosing a description. This file grows over time — keep
each rule short and unambiguous.

- If the photo is a close-up of a tape measure / ruler against a trunk, use
  "Tree Diameter Measurement".
- If the photo mainly shows a ladder, use "The Ladder".
- A wide shot showing the whole property from the street is "Property Overview",
  not "Front of Home". "Front of Home" is a framed shot centered on the house.
- Only use a "Tarp ..." description when a tarp is actually visible in the photo.
- Only use "... in Progress" descriptions when active work or workers are visible.

## Equipment — name it correctly

- Identify the machine correctly before naming it. Do not guess.
  - **Crane**: large truck with a tall boom/mast and a cable lifting from above.
  - **Mini skid**: small stand-on / walk-behind loader (Toro Dingo / Ditch Witch
    type) with a bucket or forks at ground level.
  - **Spider lift**: compact tracked machine with an articulated boom and a
    person basket.
- If you cannot tell which machine it is, use a generic term ("Equipment on Site")
  instead of naming a specific one.
- "Crane Lifting Tree" / "Crane Removing Tree" only when a crane is clearly the
  machine doing it.

## Work vs. cleanup

- "Crew Cutting Tree" / "Tree Cutting" only when a worker is visibly operating a
  chainsaw or saw and cutting wood. If workers are carrying, dragging, or loading
  debris without active cutting, use "Crew Hauling Debris".
- Loading debris into a truck/trailer by hand or with a mini skid:
  use "Mini Skid Loading Debris" if a mini skid is doing it, otherwise "Loading Debris".
- Debris cleared off the driveway → "Driveway Cleared of Debris" (not a "Loading"
  or "Yard" description).
- Never use "Cut Tree Sections in Yard". Use "Tree Debris on the Yard".

## Screen enclosure

- "Screen Enclosure Damage" / "Tree Resting on Screen Enclosure" only when a screen
  pool enclosure / lanai cage is clearly visible AND involved. If the photo mainly
  shows workers or loose debris, label that instead (e.g. "Crew Hauling Debris",
  "Tree Debris on the Yard").

## Never

- Never describe a tree or work as "trimmed", "trimming", "pruned", or "pruning".
  This company only does emergency storm work.
